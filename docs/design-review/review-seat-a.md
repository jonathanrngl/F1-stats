## 2. Whole-programme risks

- **There is no prototype isolation, so rollback is expensive.** Roles, the font import and the nav are global (Seite.astro, theme.css). The "three prototypes" are really a site-wide switch: the other ~21 page types get the grey plane, ink links and the old `--band` tints. Rolling back after a rejected prototype means reverting three shared files, plus whatever else was migrated. Implementation is already in the working tree before this review gate has closed.
- **CSP:** I found no violation in the plan. SVG presentation attributes and data attributes are fine. The risk is an implementer reaching for `style` or `define:vars` for bar heights or label positions. Ban both explicitly.
- **Accessibility:** 1.4.13 (8.4a) is a hard AA fail. 1.4.1 (Turm team) is a hard fail if the standings drop the team column. Epochenband titles fall below 3:1 (they may still pass 1.4.11 only because the Kopfsatz names the years). Focus outlines are clipped (§9). Keyboard use without JS means 77 tab stops on the home page; it doesn't fail 2.4.1 (the skip link exists), but it is poor.
- **Tests likely to break:** `:245`, `:271-273`, `:315-323` (menu and scrollWidth at 360), `:184/:199` (start-page hooks).
- **Verification tooling** is broken (§5.3 row), so "geprüft" claims in §5.4 rest on a script that can't produce them.
